## New finding

### N1 — P2: Calendar counts and calendar Excel misclassify non-expected pupils

Sources: `src/calendar-model.mjs:241` (`calendarSummary`), `src/calendar-model.mjs:262` (`calendarExportRows`), and their consumers in `src/calendar-ui.mjs` and `src/calendar-export.mjs`.

Aanwezigheden now determines whether a pupil is expected from the selected date and historical study schedule, and shows Niet verwacht separately. Calendar summaries still compute `present = roster.length - absentIds.length`. Calendar export still assigns Aanwezig/Afwezig to every pupil solely from `attendanceAbsent` once attendance has been confirmed.

This produces incorrect confirmed counts and green attendance cells for pupils who were not expected. If a non-expected pupil has an absence flag, the same logic incorrectly adds them to the absence count instead.

#### Reproduction and observed output

1. Create two synthetic pupils for Monday 2026-10-05. The first has `eveningStudy.maandag = 'Ja'`; the second has `'Nee'`.
2. Enable the calendar for that date and confirm attendance with Aanwezigheden bewaren.
3. Read the attendance heading, open the calendar and inspect the calendar workbook.

Actual results from a separate Electron profile:

| Surface | Actual result | Expected result |
| --- | --- | --- |
| Aanwezigheden | `1 aanwezig · 0 afwezig · 1 niet verwacht · 2 leerlingen` | Correct |
| Calendar detail | `2 Aanwezig`, `0 Afwezig` | 1 present, 0 absent, 1 not expected |
| Calendar workbook, first pupil | `Aanwezig` | Correct |
| Calendar workbook, second pupil | `Aanwezig` | `Niet verwacht`, with a neutral style |

The workbook was generated by `calendarWorkbook` and parsed with the app's XLSX reader. The same discrepancy was independently reproduced directly through the model functions. This does not depend on a malformed import or unusual date.

#### Recommended correction

Use one shared date-aware attendance classification for the attendance page, archived summaries and calendar export. Evaluate the archived roster's schedule for the archived date, rather than a different currently open roster. Count present and absent only among expected pupils, expose a separate not-expected count, and export Niet verwacht with a neutral style.

Add a regression fixture with expected-present, expected-absent and non-expected pupils. Verify counts, workbook labels/styles, and reopening after a later schedule change. The current attendance desktop tests cover gray non-expected cards and seating colors, but do not assert the matching calendar counts or calendar workbook status.
